- **The vendored MIR JIT moves to upstream master `439a90a2`, which includes
  the fix BNGsim carried for issue #413.** Upstream merged the
  `try_spilled_reg_mem` bounds check that BNGsim carried in `mir-gen.c`
  (vnmakarov/mir#468), so that carry is dropped. The move brings about 50 upstream
  fixes, among them two optimizer bugs that produced wrong code in loops at
  -O2/-O3, the level bngsim uses for generated sources up to 512 KB: a loop
  whose condition tests its own counter ran one iteration short
  (vnmakarov/mir#454), and an address could be folded through a loop header
  (vnmakarov/mir#467). Each MIR context now reserves 128 MB of address space
  for code on 64-bit Linux and macOS; memory is committed only as code is
  written. Only builds configured with `-DBNGSIM_ENABLE_MIR=ON` are affected.
