- **`steady_state(criterion="scaled")`: a convergence test in the model's own units** ([#1001](https://github.com/lanl/bngsim/issues/1001)). The default test, `||f(y)||_2/n < tol`, is a number in concentration per unit time, so a model in molar units or a slow one passes it far from its steady state: `X' = -k·x·(x-0.3)·(x-1)` at a scale of 1e-9 came back `converged=True` at x = 0.894, 1.003 and 0.131 after one step, where every run ends at 1. Under `criterion="scaled"` a state is accepted when the Newton step to the root, `δ = −J⁻¹f` on the reduced system, is within each species' own tolerance, `|δ_i| ≤ rtol·|y_i| + atol_i` with `atol="auto"`'s `atol_i`. The march then takes `atol="auto"` unless one is given. Every row of that example now ends at x = 1, for both methods and at 1e-12 too. Above 512 unknowns the step is not taken and the residual test applies. `steady_state_batch` takes the same argument. New on the result: `newton_distance`, the step in those units (NaN under `"residual"`, which does not take it), and `criterion`. The default stays `"residual"` until the criterion has been run across the corpus.
