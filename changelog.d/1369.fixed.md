- **`run_batch` and `run_replicates` ignored `add_stop_condition`** ([#1369](https://github.com/lanl/bngsim/issues/1369)). `run()` stops at a registered condition and raises `StopConditionMet` with the result cut there. The batch and ensemble paths returned every row to `t_end`, past the condition, with no warning. Each row is now checked the same way. A row that meets a condition is returned cut at that point, alongside the rows that ran to the end, and the new `Result.stop_condition` names the condition (`None` where none was met). Nothing is raised, so one row's stop does not cost the others. `squeeze=True` refuses a list with a cut row, since a stack cannot show which rows stopped. The result `run()` raises with now carries `stop_condition` too.
