- **An SBML model that reads `rateOf` of a variable an assignmentRule sets is now
  refused at load, by name (issue #1046).** SBML defines no rate of change for
  such a variable (L3V2 §3.4.6, validation rule 10224), and libsbml and
  RoadRunner refuse the model. In an initialAssignment, `p2 = rateOf(q)` with
  `q := 2*time` loaded with `p2 = 0`, a value the model does not have; in a rule,
  kinetic law or event it failed with an ExprTk error about an undefined
  `rate_of__q`. The error now names `rateOf(q)`, where it is read, and the rule
  that sets `q`, for the csymbol and for COPASI's rateOf functionDefinition alike.
  A kinetic law's own local parameter of the same id still reads as a constant,
  with rate 0.
