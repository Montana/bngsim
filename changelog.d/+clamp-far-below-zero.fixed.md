- **A run that carries a concentration far below 0 into a rate law with no value there is refused instead of returned.** Where the right-hand side is non-finite, GH #135 reads it again with negative concentrations set to 0. That is right for a hair below 0, and wrong far from it: BIOMD0000000338's dense run, its XIIa tipped below 0 by rounding, was read at 0 at the pole of `v·S·XIIa/(1 + XIIa)` and parked at XIIa = −1, K = −0.997 with no error. The clamp now applies within 10⁶ of the run's atol (the corpus's rescues sit at 80 to 1.3·10⁴). Where the solver's own predicted state is past that, the run raises, naming the concentration. A Newton iterate past it stays a recoverable failure, and a failed closed-form attempt still retries on the difference quotient. Also refused now: BIOMD0000000810 with `jacobian="fd"`, which returned a cell at 3·10²⁶ where the default run has 3.4. A run that steps across a pole without landing on it is not caught.
