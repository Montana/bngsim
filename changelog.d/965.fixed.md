- **A table function indexed by a function follows that function under codegen
  (issue #965).** In `g() tfun([...], [...], h)` with `h()` a model function,
  compiled code read `h` at its load-time value, so the trajectory froze at its
  initial state, with nothing raised, under `codegen=True` and on the default
  path for a model with 256 or more species. The compiled right-hand side now
  reads `h` as it evaluates it, matching the interpreter.
