- **An event whose trigger leaves its start threshold only at second order or
  past is no longer passed over in silence.** `at (B > 0)` with B = t²/2 rests
  on its threshold at the start (#340) and is not fired, as AMICI does not fire
  it; BIOMD0000000285's `p38death > 0` is the same case. The run now logs a
  warning naming each such event, with how to fire it at the start if that is
  meant (`B >= 0` with the trigger's initial value false), and
  `SolverStats.events_held_at_start` lists them. (#934)
