- **A sensitivity run with a fixed-time event and a moving one crossing on one instant, in two batches, returned one side's slope with no error** ([#1277](https://github.com/lanl/bngsim/issues/1277)). An event at `time >= 2.5` beside one on a state that a requested parameter moves to 2.5 fire a root's slack apart, as two batches. #49's refusal of two events on one instant whose times move differently was asked of one batch, so it never saw them together. Their order flips with the parameter and the result jumps there: S(3) goes from 3.75 to 4.25 across k = 1, and the run gave dS/dk = 1.25. Such a pair is now refused from either batch, as within one. A pair whose fires no requested column moves still runs.
