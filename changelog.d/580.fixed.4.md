- **Load-time folds of a kinetic law now see its Level 2 local parameters** ([#580](https://github.com/lanl/bngsim/issues/580)). Folding a reaction id that an initialAssignment or rule reads, or a `rateOf`, asked libsbml only for Level 3 local parameters, a list it leaves empty on a Level 2 law, and skipped a local parameter with no value. Either way a global parameter with the same id stood in: `p = R1` with a local `k = 0.5` and a global `k = 5` gave p = 50, where RoadRunner gives 5. A local parameter now shadows the global on both levels, and an unset one is NaN (0.0 under `BNGSIM_ALLOW_UNSET_PARAMS=1`).
