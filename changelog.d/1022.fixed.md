- **`method="rm"` runs on RuleMonkey 3.11.0, on absolute model time.** A rate
  that reads `time()`, or a table function indexed by time, now runs on `rm`
  instead of being refused (issues #862, #892), and reads model time as `ode`
  and `ssa` do: `t_span=(5, 7)` starts the initial state at t = 5. Arrhenius
  rules get BNG2's rate, with no RT divisor: `rm` gave AB = 87 where BNG2 gives
  74.7 on any energy model without `RT = 1`. A session advanced in calls
  shorter than its waiting times no longer stops firing. A rule whose products
  can never form no longer fires. `RuleMonkeySession.initialize` takes
  `t_start`, and a segment off the session clock of a model that reads it is
  refused. RuleMonkey's warnings are now `bngsim.RuleMonkeyWarning`s.
