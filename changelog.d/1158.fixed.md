- **A run no longer hangs on an event that re-arms its own trigger as it fires
  (issue #1158).** `at (B > 0): B = 0, F = F + 1` with `B' = 1` puts B back on
  its threshold, the flow makes the trigger true again at once, and the event
  fires infinitely often at one instant (Zeno behaviour): no trajectory
  continues past it. bngsim fired at every root CVODE reported, a root
  tolerance apart, and `run` never returned. Fires of one event within twice
  CVODE's root tolerance of each other are now counted as one instant, and past
  the same-instant event-loop limit (100000) the run is refused, naming the
  event. Pulse trains, however fast, are spaced by more than that and are
  unaffected.
