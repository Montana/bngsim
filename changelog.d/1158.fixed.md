- **An event that puts its own trigger back on its threshold is refused by name instead of hanging** ([#1158](https://github.com/lanl/bngsim/issues/1158)). `at (B > 0): B = 0` with the flow carrying B straight back above 0 fires infinitely often, at times that accumulate at its first fire (Zeno): every 6e-27 from t = 0, or every 5.6e-15 after a reset at 0.5. `Simulator.run` never returned. Such a model has no continuation, so the ODE run now raises `SimulationError` naming the event once it has fired 1000 times in a row, each within 1e-9 of max(|t|, horizon) of the last. That window is 1000 times tighter than the chatter guard's and sets no condition on how much the fire changes the state. A real event train trips it only past 1e9 fires per horizon.
