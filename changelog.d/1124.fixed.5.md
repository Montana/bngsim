- **A call to a functionDefinition whose body reads `rateOf` now takes the
  rate of what is passed, where it was refused at load.** `h(y) = rateOf(y)`
  (COPASI's rateOf idiom), called as `h(S)` in an assignment rule, an
  initialAssignment or an event, is written out at the call as `rateOf(S)`
  before the load checks it, so the initial-value fold, the rules and codegen
  read S's rate, through any number of such functions. A call whose argument
  is not a single symbol, `h(2*S)`, is refused as `rateOf(2 * S)` is (rule
  10223). A call with the wrong number of arguments, or to a function that
  calls itself (rule 20512), is refused by name. (#1124, item 8)
