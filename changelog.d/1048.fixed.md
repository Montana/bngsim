- **A folded SBML initial value that reads the `rateOf(x)` csymbol no longer
  freezes `x`, and the load warning about what such a value froze now names what
  `set_param` refuses (issue #1048).** `rateOf(x)` does not read `x`'s value: in
  SBML Test Suite 01249, `p2 = rateOf(p1)` is 0 whatever `p1` is, yet
  `set_param("p1", ...)` and a sensitivity with respect to `p1` were refused. They
  are allowed now; `x` is still frozen where the initial value also reads it
  outside the `rateOf`, or calls COPASI's rateOf functionDefinition on it. The
  warning about an initialAssignment bngsim could not keep symbolic read the
  expression's names alone, so it named `p1` there and printed nothing for
  `p2 = rateOf(B)` under `J0: A -> B; k1*A`, whose `k1` and compartment size were
  refused. It is now built from the same list as the refusal, and gives the names
  `set_param` takes.
