- **Writing a `.net` now warns when a species an assignment rule sets is written so that only bngsim reads it as meant.** The writer emits such a species `$`-fixed, beside the observable or function that holds its rule under the species' own name. bngsim's reader takes the pair as the rule, but BioNetGen's `run_network` holds the species at its initial value for the whole run, with no message: `B := 2*A` read B = 20 at t = 5 in `run_network` against 1.64 in bngsim, and on BIOMD0000000144 every rate law reading `$Wee1Pc` ran wrong. `write_net` (and `sbml_to_net`) now raise a `ConversionWarning` naming those species, and `capability_report` lists them under a new `bngsim_only` key. The file is unchanged and still exact for bngsim, so the warning is never a refusal, `strict=True` included (issue #1274).
