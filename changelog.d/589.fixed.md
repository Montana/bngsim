- **A reaction whose rate parameter never resolved is refused at build instead
  of running with a rate of zero (issue #589).** The rate kernel answers an
  unresolved rate-parameter index (Elementary/Functional) or kcat/Km index
  (Michaelis-Menten) with a propensity of 0.0, so such a reaction was dead for
  the whole run with nothing reporting it. `ModelBuilder.build()` now checks
  every reaction's resolved indices and raises, naming the reaction. The check
  is at build rather than in the kernel, which runs inside CVODE's C callback
  where an exception must not propagate. From @Montana.
