- **A dilution term that reads a species' rate keeps the analytic Jacobian
  and the analytic sensitivity RHS.** With `C1 := 2 + r*P` and S in C1, S's
  dilution term reads `rate_of__P`, the engine's live dP/dt, which no
  derivation could differentiate: both were declined, a sensitivity run at
  rtol 1e-11 took 291,511 steps on CVODES' difference quotient, and
  `sensitivity_ic` could not run. The derivations now read P's rate as the sum
  of the rates of the reactions that change P, which is the same value, for
  mass-action and rate-law reactions alike; the same run takes 284 steps and
  agrees with finite differences. A rate stays unread, and the model on the
  difference quotient, where a reaction that changes P divides by each
  species' volume (one across compartments of different sizes) or is
  Michaelis–Menten, or where P is an amount whose `rateOf` reports an amount.
  The compiled Jacobian of a model that reads a rate no longer fails to build
  where it recomputes the model's functions (a cross-compartment reaction into
  a rate-ruled compartment): it writes out the rates it can and declines where
  it cannot. (#1124, item 7)
