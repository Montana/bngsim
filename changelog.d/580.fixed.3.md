- **A network-free `<Parameter>` with no `expr=` and an unreadable `value=` is refused when overrides apply** ([#580](https://github.com/lanl/bngsim/issues/580)). `NfsimSession.set_param` and `evaluate` re-evaluate the XML's parameters, and such a parameter read as 0.0 there, as did an overflowing `value="1e400"`. It now raises naming the parameter, and `1e400` reads as `inf`. BNG2.pl writes an `expr=` on every parameter, so its XML is unaffected.
