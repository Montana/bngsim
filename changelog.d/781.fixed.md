- **The Jacobian sparsity pattern dropped every species a table function reads
  through an observable or function index (issue #781).** The builder rewrites a
  tfun-bodied function to `tfun_<name>()` before the pattern is built, so the
  index was no longer in the text the dependency scan reads. `Model.jacobian(sparse=True)`
  returned 0 where the dense and finite-difference Jacobians are nonzero;
  `pure_sink_species()` reported the indexed species as an inert accumulator;
  and the steady-state masking recipe built on that list froze it and reported
  a steady state the dynamics never reach. `build_jac_sparsity` now resolves
  each `tfun_<name>` call (including the synthetic name of an embedded call) to
  its index: an observable index contributes its species, a function index
  becomes a function-to-function edge. Time- and parameter-indexed tables read
  no species, and their pattern is unchanged. From @Montana.
