- The Table S4 agreement check (`benchmarks/suites/ode_engines_s4_sbml/check_sbml_engine_agreement.py`) judges whether the engines compute the same trajectory against a converged reference, not against bngsim at the timing tolerance (issue #1250). At rtol 1e-6, Koo2013's final state swings by up to 7% with the number of output rows in every engine, so the old verdict (bngsim 4.8% off libRoadRunner, under a 5% bar) measured the tolerance, and the grid passed or failed it. The check now integrates the model at rtol 1e-12, atol 1e-15 (libRoadRunner, or bngsim where libRoadRunner fails, as on Smith2013). `agree` asks whether each engine at those tolerances is within 1e-4 of that reference; converged, the six models' engines agree to 5.5e-8 or better. Each engine's error at the figure's own tolerances is reported beside it as `*_error_at_timing_tolerances` (on Koo2013: bngsim 4.7%, libRoadRunner 0.15%, COPASI about 0.1%), and the old `bngsim_vs_*` differences are kept. The report's version lookup no longer fails after every engine has run where COPASI is not installed.
