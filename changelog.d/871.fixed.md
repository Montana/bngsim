- **An SBML initialAssignment the load-time fold cannot evaluate no longer leaks
  a declared value into other targets (issue #871).** Issue #732 put such an
  initialAssignment back on the engine for a parameter or species target. A
  compartment or speciesReference target still kept its declared size or
  stoichiometry, and an initialAssignment that read a failed target folded with
  that target's declared value (`Q = S + 1` loaded as 6 where `S = 1/0`). Each
  is now refused, naming the target and the failed initialAssignment it reads.
  A target the engine evaluates, such as a parameter reading a failed parameter,
  still loads with its IEEE value. A `piecewise` whose condition the fold could
  not decide also chose a later branch as if that condition were false; the
  engine now evaluates it (`piecewise(1, 1/0 > 0, 2)` is 1). From @Montana.
