- **An SSA run from a large `t_start` lost waiting times in a model whose rates read the clock** ([#1059](https://github.com/lanl/bngsim/issues/1059)). The doubles near t = 1e12 are 1.2e-4 apart. The continuous loop placed its firings on panels in absolute time, where a waiting time below that spacing rounded away. A decay `k*A*(1 + 1e-30*time())` came back at 22829 for an exact 36788 from `t_start = 1e12` (z = −289); #1075 had fixed the discrete loops only. A rate held between breakpoints went back to 0 after its first firing, because the clock just past the breakpoint rounded onto it. Above `|t_start| = 2^20`, an SSA or PSA run now counts its clock from `t_start` and gives the model `t_start + elapsed` wherever it reads the clock. Rows report the times asked for, and the state and the events carried to the next run keep their absolute times. Runs nearer the origin are unchanged, to the bit.
