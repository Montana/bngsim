- **`jacobian="jax"` died with `NameError` on `log10()`, and on every other
  engine name the translator's table had never been given (issue #565).** The
  table stopped at seventeen functions, and `\blog\b` cannot cover `log10`, so
  it reached the generated source untranslated and failed mid-solve as
  `NameError: name 'log10' is not defined` — on a model the ODE backend and
  `jacobian="auto"` both run, with nothing documenting it as unsupported.

  Every reserved engine name that jax.numpy spells directly is now mapped:
  `log10`, `log2`, the hyperbolics and their inverses, `round`, `trunc`,
  `sign`/`sgn`, the constants `_pi` and `_e`, and the bare `time`. What is
  still unmapped — `erf`, `erfc`, `tgamma`, `clamp`, `avg`, `sum` and the table
  functions, none of which worked before either — is now refused at translation
  time, naming the function and pointing at `jacobian="auto"`, so it surfaces
  where the caller can act on it rather than as a `NameError` inside the solve.
  From @Montana.
