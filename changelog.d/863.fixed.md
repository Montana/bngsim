- **`ModelBuilder` no longer builds a silently wrong model from three inputs
  (issue #863).** An elementary or functional reaction with an empty rate name
  built and never fired; it is now refused, naming the reaction. A functional
  reaction whose rate names a parameter and no function also never fired; it
  now resolves as elementary at that parameter, the mirror of the existing
  elementary-to-functional reclassification. A species IC reference
  (`add_species_param_ref`) to an undeclared parameter was dropped, leaving the
  species at its `add_species` number with no reference recorded; it is now
  refused, naming the species and the parameter, as is a species index out of
  range. The SBML loader, which relied on the drop for a parameter it promotes
  to a species, now leaves that reference out itself. From @Montana.
