- **`method="rm"` keeps the waiting times of a model that reads `time()` from a large `t_start`** ([#1063](https://github.com/lanl/bngsim/issues/1063)). Since #1022 such a model ran on absolute model time, and RuleMonkey places each event at `t + tau` in doubles, so once the total propensity times |t| neared 1e15 the waiting times rounded away and the run was biased with no error: from t = 1e12 the survival of 20000 molecules at 0.5 came back 10.8 standard errors low. A run, and a `RuleMonkeySession`, now integrate on elapsed time from a copy of the XML whose functions read `time() + t_start`, so rates and output functions still read model time, as do a session's `current_time`, `step_to`, `evaluate` and `save_state` snapshots. A model with a table function indexed by time still runs on model time: offsetting a table's clock would index it through a function, on which RuleMonkey 3.11.0 recurses without end (richardposner/RuleMonkey#111).
