- **Codegen copied parts of a rate law into the C it compiles that C has no meaning for** ([#1212](https://github.com/lanl/bngsim/issues/1212)). These were ExprTk's `frac`, `inrange`, `iclamp`, `roundn`, `root`, `logn`, `sinc`, `equal`, `cot`, `sec`, `csc`, `ncdf`, `deg2rad`, `rad2deg` and the rest; a table read as `tfun_kf` or `tfun_kf ()`; a name with a dot; an implicit product such as `2tfun_kf()`; and `_R`, `_NA`, `_kB`, `_h`, `_F`. cc refused the source after automatic codegen had paid for the compile, and the MIR JIT refused it outright. Each is now C written from ExprTk's own arithmetic. That includes `hypot` and `log2`, whose C versions differ from ExprTk's (`hypot(1e200, 1e200)` is `inf` to the engine). Anything still untranslated declines before a compiler sees it.
