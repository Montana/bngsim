- **An SSA or PSA run that starts far from t = 0 no longer loses its waiting
  times to rounding.** Each firing was placed at `t + tau` in doubles. Near
  `t = 1e12` those are 1.2e-4 apart, so a shorter waiting time was lost whole.
  A decay of 1e5 copies at k = 0.5 from `t_start = 1e12` read 22,928 at
  `t_start + 2`, against the exact mean of 36,788 (z = -287). From 1e15 it ran
  fast instead (z = -762). The part each firing rounds away is now carried into
  the next one, and samples are read against each firing's exact time. A run
  whose rates do not read the clock now gives, seed for seed, exactly the run it
  gives from `t_start = 0`. A rate that reads `time()` goes through the
  continuous loop, which still has this limit (#1059).
