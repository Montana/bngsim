- **An SBML concentration species in a compartment whose assignment rule reads a
  species now changes with the compartment's size (issue #1052).** SBML keeps such
  a species' amount, so its concentration is amount/V(t). With `cv := 1 + 0.1*S`,
  bngsim kept every concentration in `cv` instead, constant, boundary, ordinary or
  reacting, with nothing said: `[Sk]` stayed 5 where it reaches 7.31 by t = 2, as
  libRoadRunner and the closed form give. The size's rate now takes each species
  it reads at its live rate, through assignment rules as well; such a model then
  runs the rateOf machinery, so an explicit `jacobian="analytical"` is declined for
  it as for any rateOf model, and the default picks a finite-difference Jacobian. A
  size that reads a concentration in its own compartment, directly or through a
  ring of such compartments, is refused by name, as libRoadRunner refuses it,
  since the size and the concentration define each other; so is one that reads an
  amount in another rule-sized compartment, whose rate is still wrong there (#736).
